# The Author's Nexus

> A portfolio masterpiece for a Copywriter · Poet & Writer · Mobilographer.
> Built with no compromise, no deadline, and no shortcuts.

A triptych portfolio site — three realms, one author, one soul.

## What is this?

The Author's Nexus is a high-craft digital portfolio for a creative professional working across three disciplines: copywriting (The Atelier), poetry & prose (The Library), and mobile photography (The Frame).

Each realm has its own visual language, palette, typography, and emotional register — yet all three share one underlying navigation logic and one author identity.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 15 (App Router) + TypeScript strict |
| Styling | Tailwind CSS v4 + CSS Custom Properties |
| Animation | Framer Motion + GSAP *(Sprint 1+)* |
| CMS | Sanity v3 (Studio at `/studio`) |
| Database | Supabase (Postgres) |
| i18n | next-intl v3 — 4 locales (az, en, ru, tr) |
| Fonts | Cormorant Garamond · Inter · JetBrains Mono · Fraunces |
| Deployment | Vercel |

## Quick Start

See **[docs/SETUP.md](docs/SETUP.md)** for full setup instructions.

```bash
git clone https://github.com/musbabaff/authors-nexus.git
cd authors-nexus
cp .env.example .env.local
# Fill in .env.local with your actual keys
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

Sanity Studio: [http://localhost:3000/studio](http://localhost:3000/studio)
